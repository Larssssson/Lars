# Archive — the original nine-tool suite

These documents describe the first pass: a general-purpose tool suite for
public affairs consultancy (Ledger, Pitch, Redline, Table, Signal,
Dossier, Whip, Readout, Bridge), built around a per-client context layer.

**Superseded.** An interview established that the actual target is
narrower and more valuable: a scanning and qualification system for
German public funding and public procurement opportunities. See the
repository root.

Three things from this pass carried forward and are worth reading here for
the fuller argument:

- **"No source, no sentence"** — every factual claim carries a pointer, and
  unsourced claims render as visible gaps rather than fluent prose.
- **"Draft to the last mile, never to the client"** — outputs are addressed
  to a consultant, in draft, with weak spots marked.
- **The context-layer inversion** — tools are thin, the structured context
  is the asset. In the current design this becomes the eligibility profile.

Three things were wrong and are worth recording as such:

- It assumed EU institutional work (trilogue, rapporteurs, OEIL). The real
  centre of gravity is DACH, where the process is different.
- It assumed build capacity that does not exist. Word add-ins, mobile
  capture and a database are not buildable by one consultant.
- It picked the wrong wedge. Readout depended on a phone surface, and
  without one its capture half collapses.
